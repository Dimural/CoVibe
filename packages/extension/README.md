# CoVibes Extension

Real-time collaborative AI-assisted coding sessions for VS Code.

## Features

- **Start Session**: Begin a new collaborative coding session
- **Join Session**: Join an existing session by ID
- **Leave Session**: Disconnect from the current session

## Commands

| Command                  | Description                       |
| ------------------------ | --------------------------------- |
| `CoVibes: Start Session` | Start a new collaborative session |
| `CoVibes: Join Session`  | Join an existing session          |
| `CoVibes: Leave Session` | Leave the current session         |

## Requirements

- VS Code ^1.95.0
